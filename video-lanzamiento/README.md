# Video de lanzamiento de marca (Remotion)

Video de 60 s sin narrador, en dos formatos:
- `Lanzamiento-Vertical`: 1080x1920 (Reels, TikTok, Stories)
- `Lanzamiento-Horizontal`: 1920x1080 (YouTube, página web)

## Estructura
| Seg. | Escena | Imagen |
|---|---|---|
| 0–5 | Panamá crece | Bahía de noche |
| 5–20 | Problemas: burocracia, espera, banco, desisten | Av. Balboa / Cinta Costera (B/N) |
| 20–22 | "Hasta hoy." | Transición |
| 22–36 | Entramos nosotros, +años, ventajas | Skyline Balboa, el Tornillo |
| 36–44 | Fortaleza y visión | El Tornillo y la ciudad |
| 44–52 | Página web con servicios | Maqueta de navegador |
| 52–60 | Logo + redes sociales + web | Cierre |

## Personalizar
Edita **`src/config.ts`**: nombre, slogan, años, web, servicios, redes, logo (`public/logo.png`) y música (`public/musica.mp3`).

## Comandos
```bash
npm install
npm run studio            # vista previa interactiva
npm run render            # genera out/lanzamiento-vertical.mp4 y out/lanzamiento-horizontal.mp4
```
