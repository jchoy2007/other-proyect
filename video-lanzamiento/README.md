# Video de lanzamiento · Holding Realty Properties (Remotion)

Video de 60 s sin narrador, en dos formatos:
- `Lanzamiento-Vertical`: 1080x1920 (Reels, TikTok, Stories)
- `Lanzamiento-Horizontal`: 1920x1080 (pantalla del evento, YouTube, web)

## Estructura (v2)
| Seg. | Escena |
|---|---|
| 0–5 | Una familia en Panamá por fin encontró su apartamento (skyline de Balboa) |
| 5–8 | Y entonces empezó el trámite (la imagen pasa a blanco y negro) |
| 8–16 | Cinco puertas: promotora, corredor, banco, afianzadora, abogado… y la venta se cae |
| 16–19 | Cinco puertas. Una sola llave. |
| 19–26 | Irisbel Tapia, Fundadora y CEO: 25 años en banca |
| 26–30 | Por eso nació Holding Realty Properties |
| 30–35 | HRP vende el inmueble y CHS lo lleva hasta el desembolso |
| 35–40 | Un solo acompañante: 6 pasos (el Tornillo de fondo) |
| 40–45 | Desde la Torre BICSA, frente a la bahía |
| 45–51 | Página web: www.holdingrealty.com |
| 51–60 | Logo, slogan, contacto y redes |

**Música:** `public/audio/musica-provisional.mp3` es la pista del video anterior, ajustada a 60 s. Hay que confirmar su licencia o reemplazarla.

## Personalizar
Edita **`src/config.ts`**: textos, contacto, servicios, pasos y música. Los logos oficiales están en `public/logos/` y las fotos de la marca en `public/marca/`.

## Comandos
```bash
npm install
npm run studio            # vista previa interactiva
npm run render            # genera out/lanzamiento-vertical.mp4 y out/lanzamiento-horizontal.mp4
```
